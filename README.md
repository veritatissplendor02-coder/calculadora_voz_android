# Calculadora por Voz — V2.2 — Histórico completo e rolável

Esta atualização mantém a conta atual visível em **EU OUVI**, como na versão 2.1.

- Role a tela com o dedo para acessar o histórico.
- O botão **VER HISTÓRICO** leva diretamente à lista de cálculos.
- O botão **VOLTAR AO INÍCIO** retorna ao resultado e ao microfone.
- O histórico mostra **todas** as contas, da mais recente à mais antiga, sem limite de oito.
- O histórico fica salvo no próprio aparelho após fechar e reabrir o aplicativo.
- O botão **Apagar conta atual / nova conta** e os comandos de voz "apagar", "limpar" ou "zerar" não apagam o histórico.
- **APAGAR HISTÓRICO** remove os registros somente depois de uma confirmação.
- A escuta contínua e os resultados continuam funcionando como antes.

**Atenção:** contas feitas em versões anteriores não podem ser recuperadas após fechar aquelas versões: a V2.2 começa a salvar o histórico a partir da atualização. Se desinstalar o aplicativo ou apagar os dados dele no Android, o histórico salvo poderá ser perdido.

Para gerar o APK no Windows, use `GERAR_APK_V22_HISTORICO_COMPLETO.bat`, preferencialmente no computador utilizado para compilar a instalação anterior, preservando a assinatura de depuração.
